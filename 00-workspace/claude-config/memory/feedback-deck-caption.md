**Rule:** Caption WhatsApp untuk deck tidak boleh mengandung "salam kenal, aku Steven" atau intro yang serupa.

**Why:** Prospek sudah tahu dari VIRA siapa yang mengirim (Steven dari Scholars); intro pribadi itu redundan dan membuat caption lebih panjang.

**How to apply:** Saat generate deck, caption harus langsung ke poin (deck untuk bisnis apa, request untuk feedback paket mana). Lihat `caption-deck.txt` — pastikan template tidak punya intro pribadi.
