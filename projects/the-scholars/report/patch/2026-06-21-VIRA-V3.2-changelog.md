# VIRA V3.2 — Changelog (21 Juni 2026)

Basis: `2026-06-21-VIRA-V3.1.json` (TIDAK ditimpa). File baru: `2026-06-21-VIRA-V3.2.json` (55 node, JSON valid, syntax JS OK).

## Masalah yang diperbaiki
Saat re-test, link GForm kadang tidak terkirim / salah link. Akar:
1. Pengiriman link hanya dipicu string literal `[SEND_GFORM]`; Haiku kadang tidak menulis tag persis → tidak terkirim (non-deterministik).
2. `Send GForm Link` selalu ambil `URL` baris pertama LINKS (= Batch 5) tanpa filter program, dan teks pesan **hardcoded "Mock Interview"** → link/keterangan bisa salah untuk Seniors/Mock.

## Solusi (data-driven, tanpa tag per-program)
Tetap satu tag `[SEND_GFORM]`, tapi AI menyertakan **Nama Link persis** dari sheet sebagai parameter: `[SEND_GFORM: <Nama Link>]`. Tambah row baru di sheet LINKS = otomatis bisa dipilih AI, tanpa ubah kode.

### Perubahan node
1. **AI Agent (system message)** — instruksi `# TAG`: WAJIB tulis `[SEND_GFORM: <Nama Link>]` memakai nama persis dari daftar "LINK AKTIF"; dilarang `[SEND_GFORM]` tanpa nama; kalau ragu link mana → jangan pasang tag, tanyakan dulu.
2. **FAQ Retrieve (`data_context`)** — daftar LINK AKTIF kini menyertakan **deskripsi** tiap link + contoh format tag, supaya AI bisa mencocokkan program→link sendiri.
3. **Process All** — regex diperluas menangkap `[SEND_GFORM:nama]` → `gformLinkName`; strip toleran (`[SEND_GFORM]` & `[SEND_GFORM: ...]`); `gformLinkName` diteruskan ke downstream. Fallback frasa lama tetap (akan diarahkan ke "tanya ulang").
4. **Pick GForm Link (node baru, Code)** — disisip antara `Query LINKS for GForm` → `IF GForm Resolved`. Mencocokkan `gformLinkName` ke baris LINKS aktif (exact → partial, case-insensitive), ambil `URL`+`Deskripsi`, dan **bangun pesan dinamis** dari deskripsi (tidak lagi hardcoded "Mock Interview"). Aman bila sheet kosong/URL hilang.
5. **IF GForm Resolved (node baru)** — `gformResolved === true`:
   - **true** → `Send GForm Link` → `Update GForm Sent TS1` (kirim link, catat timestamp).
   - **false** → `Send GForm Clarify` (node baru) → **tanya ulang link mana** dengan daftar pilihan; TIDAK mencatat timestamp.
6. **Send GForm Link** — `message` & `phone` kini dari output `Pick GForm Link` (`$json.message`, `$json.phone`).
7. **Send GForm Clarify (node baru)** — klon Kirimi dari `Send GForm Link`, kirim pesan klarifikasi.

### Koneksi
`IF Send GForm (true)` → `Query LINKS for GForm` → `Pick GForm Link` → `IF GForm Resolved` → (true) `Send GForm Link` → `Update GForm Sent TS1` / (false) `Send GForm Clarify`.
