# Manajemen Proyek v5 — Versi General (untuk Konten Reels)

Versi **v5** adalah turunan dari v4 (TIM Interior) yang sudah **dipolos­kan / di-general­kan**: semua branding "TIM Interior" dihapus, gaya divisualkan ulang ke arah **modern-elegan**, dan tampilan dibuat netral supaya cocok dipakai untuk **konten reels Instagram** — bukan untuk satu kantor tertentu.

Secara teknis backend-nya **sama persis dengan v4**: tetap memakai **n8n + Google Sheet yang eksisting** (endpoint `/v4/...`). Jadi v5 ini langsung jalan tanpa perlu setup ulang server atau sheet.

## Folder

```
v5/
├─ webform/                       ← upload isi folder ini ke hosting
│  ├─ index.html                  ← aplikasi (PWA) — branding netral, live data
│  ├─ manifest.json               ← nama app "Manajemen Proyek"
│  ├─ sw.js                       ← service worker (cache "manajemen-proyek-v5")
│  ├─ logo.png                    ← logo mark baru (netral)
│  └─ icon-*.png / apple-touch-icon.png
└─ 2026-06-22-catatan-v5.md       ← catatan ini
```

## Apa yang berubah dari v4

| Nama / judul | "TIM Interior" | "Manajemen Proyek" (fungsional, tanpa nama perusahaan) |
| Home header | Logo TIM + judul "TIM *Interior*" | Logo mark netral + "Manajemen *Proyek*" + tagline "Catat · Pantau · Rencanakan" |
| Logo & ikon | `logo_tim.jpg` | `logo.png` + set ikon baru (tile charcoal + bar emas, gaya minimalis) |
| Dashboard eyebrow | "DASHBOARD MONITORING · TIM INTERIOR" | "DASHBOARD MONITORING" |
| Gaya visual | Gold + cream | Tetap gold-cream elegan, tapi di-refresh: sudut lebih lembut (radius 18px), shadow lebih halus/berlapis, spacing lebih bersih |
| Data demo | Nama asli (Ko Ronald, Hendi, Mita, ID "TIM-…") | Diganti mock baru: proyek **Rumah Kebun Jeruk, Apartemen PIK, Kantor Pondok Indah**; pekerja Rizal Hakim, Yusuf Maulana, Bayu Pratama, dll |
| Backend | n8n `/v4/` + Google Sheet | **Sama** — tidak diubah |

Backend, struktur 7-tab Google Sheet, dan ke-11 endpoint **tidak diubah** sama sekali — fungsi aplikasi (catat pekerjaan, komplain, cek status, dashboard, generate RAB/checklist) identik dengan v4.

## Cara deploy

1. Upload **seluruh isi folder `v5/webform/`** ke hosting statis (Netlify / Vercel / cPanel / GitHub Pages). Pastikan semua file dalam satu folder yang sama.
2. Tidak perlu setup n8n atau Google Sheet lagi — sudah menunjuk ke instance v4 yang aktif (`https://n8n.srv1270416.hstgr.cloud/webhook/v4/...`).
3. Buka di HP → "Add to Home Screen" untuk pengalaman PWA penuh (fullscreen, ada ikon).

## Mode demo / rekaman reels

- **Saat ini `TEST_MODE = true`** (baris ~1717 di `index.html`) → aplikasi jalan **penuh tanpa server**, pakai data mock netral (proyek Rumah Kebun Jeruk, Apartemen PIK, Kantor Pondok Indah; pekerja Rizal Hakim dkk). Aman tampil di kamera dan tidak menyentuh data asli.
- **Semua flow normal bisa diselesaikan sampai sukses di mode demo:**
  - **Dashboard** — 3 proyek lengkap (KPI, budget vs realisasi, tiket terbaru, beban kerja PIC).
  - **Catat Pekerjaan** — isi item RAB → Simpan → layar sukses; data masuk ke list demo (muncul di Cek & RAB).
  - **Catat Komplain** — isi → Kirim → layar sukses; komplain ikut tersimpan ke list demo.
  - **Cek Pekerjaan** — cari per proyek/pekerja → ubah status (Pending/Proses/Selesai) → Simpan → sukses; **status tersimpan & tetap** saat dicari ulang.
  - **Generate RAB / Checklist** — pilih proyek → buka jendela cetak (bisa Save PDF).
  - **+ Tambah Proyek / + Tambah Pekerja** — langsung masuk ke dropdown.
- **PENTING sebelum deploy live:** ubah kembali ke `const TEST_MODE = false;` supaya aplikasi membaca/menulis ke Google Sheet v4 yang asli.
- Dark/light: tombol toggle tema di pojok kanan atas tiap layar (preferensi disimpan lokal, key `app-theme`).
